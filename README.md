# pi-skill-domain-modeling

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-domain-modeling)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**domain-modeling** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Build and sharpen a project's domain model. Use when discussing codebase terminology, writing or editing a GLOSSARY.md, or recording or editing an ADR.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-domain-modeling
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-domain-modeling.git ~/.pi/agent/skills/domain-modeling

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-domain-modeling.git ~/.agents/skills/domain-modeling
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:domain-modeling
```

Or let Pi automatically route to it based on conversation context and need.
